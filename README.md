# BraveHeart — Pasang Ring Jantung (High Quality PCI)

Landing page statis untuk GitHub Pages. Semua gambar di-host sendiri di folder `images/`.

## Cara pakai
1. Salin folder ini ke `Desktop/GitHub_YanuarNorman/braveheart-pci`.
2. Unduh semua gambar (sekali saja), dari dalam folder ini:
   - macOS / Linux / Git Bash: `bash download-images.sh`
   - Windows PowerShell: `powershell -ExecutionPolicy Bypass -File download-images.ps1`
3. Tambahkan 2 gambar award secara manual (lihat di bawah).
4. Commit & push. Halaman akan tayang di https://yanuarnorman.github.io/braveheart-pci/

## Gambar yang harus ditambahkan manual
Unduh dari bagian "Penghargaan & Pencapaian" di brawijayahospital.com, simpan dengan nama persis:
- `images/award-cnn-wellnest-2026.webp` — Special Recognition for Excellence in Cardiovascular Care (CNN Indonesia Wellnest Curated Picks 2026)
- `images/award-indomedex-2026.webp` — Leadership in Service Excellence (INDOMEDEX Awards 2026)

Sampai file ini ada, kartunya tampil tanpa gambar (tidak muncul ikon rusak).
